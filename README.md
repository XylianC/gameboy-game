# Untitled Gameboy Game

## Some information
I have always been fascinated by gameboy games. 
I never considered making one myself as I thought I required learning assembly
to do this.

Then I realised, writing C (which is something I'm actively learning) is a valid way of making a gameboy game. 
There are tools like GBDK-2020 which make the compilation much friendlier for beginners!

## Sources 
I used the amazing tutorial by [GamingMonsters](https://www.youtube.com/@GamingMonsters) to get started.
This helped me set up the gb development environment, as well as learn the basics, recommended!


* I use BGB for emulating the game, it has handy built in VRAM debug tools
* [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) (Gameboy Development Kit 2020)
* [GBTD](https://www.devrs.com/gb/hmgd/gbtd.html) (Gameboy Tile Designer) by Harry Mulder
* [GBMB](https://www.devrs.com/gb/hmgd/gbmb.html) (Gameboy Map Builder) by Harry Mulder
* Aseprite
